# Tours & Travels Booking & Sales Analytics Dashboard 📊

## 📌 Project Overview

This project is an **Excel-based Tours & Travels Booking & Sales Analytics Dashboard** created to analyze travel booking and sales data and convert raw data into meaningful business insights.

The project demonstrates how **Microsoft Excel** can be used for data analysis, Pivot Tables, Pivot Charts, KPI calculations, interactive slicers, and dashboard creation.

The dashboard provides a visual overview of booking performance, revenue, destinations, package types, booking status, payment methods, and salesperson performance.

> Note: This project is created as an academic/practical Data & Business Analytics project to demonstrate Excel-based data analysis and dashboard development skills.

---

## 🎯 Project Objective

The main objectives of this project are:

- Analyze overall Tours & Travels booking performance
- Analyze total revenue generated from bookings
- Calculate important Key Performance Indicators (KPIs)
- Analyze revenue based on destinations
- Analyze bookings based on package types
- Analyze booking status and overall booking distribution
- Analyze monthly revenue and booking trends
- Analyze different payment methods
- Analyze salesperson performance
- Create interactive Pivot Tables and Pivot Charts
- Create an easy-to-understand and professional Excel dashboard
- Provide meaningful insights from travel booking data

## 📂 Project Structure

The Excel workbook contains the travel booking dataset and dashboard analysis.

### 1. Tours & Travels Dataset

This sheet contains the raw booking data used for the project.

The dataset includes information related to:

- Booking ID
- Booking Date
- Customer Information
- Destination
- Package Type
- Number of Travelers
- Booking Status
- Payment Method
- Revenue
- Salesperson
- Travel-related booking details

The dataset is used as the primary source for creating Pivot Tables, charts, KPIs, and dashboard visualizations.

---

### 2. Pivot Table Analysis

The analysis section contains multiple Pivot Tables created from the original dataset.

The major analyses include:

- Revenue by Destination
- Package Type-wise Bookings
- Booking Status Analysis
- Monthly Revenue Analysis
- Payment Method Analysis
- Salesperson Performance

These Pivot Tables help summarize the raw booking data and make it easier to identify important business patterns and trends.

---

### 3. Dashboard

The final dashboard provides a visual summary of the Tours & Travels business performance.

The dashboard includes important KPIs such as:

- **Total Bookings**
- **Total Revenue**
- **Total Travelers**
- **Average Booking Value**

The dashboard also contains visualizations for:

- Revenue by Destination
- Package Type-wise Bookings
- Booking Status
- Monthly Revenue Trend
- Payment Method
- Salesperson Performance

Interactive slicers are included to filter and explore the dashboard based on different categories and booking attributes.

## 📊 Key Analysis

### Revenue by Destination

The dashboard analyzes the total revenue generated from different travel destinations.

This helps identify destinations that contribute significantly to overall business revenue and allows destination-wise performance to be compared easily.

---

### Package Type-wise Bookings

Bookings are analyzed according to different package types.

This provides an overview of customer preferences and helps understand which travel packages receive more bookings.

---

### Booking Status

The dashboard provides a breakdown of booking statuses such as:

- Confirmed
- Pending
- Cancelled

This analysis helps understand the overall booking distribution and the proportion of successful and unsuccessful bookings.

---

### Monthly Revenue Trend

Monthly revenue is analyzed using a combination chart to visualize the relationship between:

- Monthly Revenue
- Number of Bookings

This makes it easier to identify changes in travel sales performance over time.

---

### Payment Method Analysis

The project analyzes bookings according to different payment methods.

This helps understand customer payment preferences and the distribution of transactions across available payment options.

---

### Salesperson Performance

Salesperson performance is analyzed based on booking and revenue-related metrics.

This provides a comparison of sales performance and helps identify individual contribution to overall travel sales.
